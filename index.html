The Prompt Cookbook - V2

Practical ways to put AI to work at your nonprofit.

Turn the files, information, and examples you already have into useful tools, clearer data, reusable content, and repeatable workflows. No coding required.

Welcome to the Prompt Cookbook V2! At Decoded Futures we see nonprofits wrestle daily with what AI can really do for them, so we put together our favorite quick, practical prompts and “recipes” that we've seen improve daily nonprofit work. After the success of the Prompt Cookbook V1 that we launched exactly a year ago, we released this new version to showcase some of the new, powerful ways AI can help nonprofits that they couldn't a mere 12 months ago. Of course the V1 Cookbook is still relevant today so hop there if you can't find what you're looking for here.

Please send any feedback you have to info@decodedfutures.nyc and we hope you enjoy!

How to Use This Cookbook

Step by step

  1. Browse or search — use the sections or the search bar to find a task you actually face.
  2. Pick a version — each recipe's prompt has a Simple and a Detailed version; start with Simple if you're new to AI.
  3. Copy the prompt — click Copy and paste it straight into ChatGPT, Claude, Gemini, or Copilot.
  4. Customize — replace the [PLACEHOLDERS] with your organization's details.
  5. Send and iterate — refine the result with follow-up questions.

Tips for success

  • Be specific — swap the placeholders for your real details.
  • Ask for changes — if the first result isn't right, say “make it more formal” or “add detail about X.”
  • Try another recipe — if one doesn't fit, a neighboring one in the same section might.
  • Save what works — keep a copy of prompts that work well for your organization.
