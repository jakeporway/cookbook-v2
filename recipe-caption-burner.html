Add captions to any video

A small tool that runs on your own computer. Drop a video on it and get the video back with captions burned in, for accessibility, for social, and for everyone watching with the sound off. The video never uploads anywhere.

Nothing to flag. No sensitive data goes in, and nothing gets published
Information you give it

Nothing sensitive. You describe what you want the tool to do, and no video is attached while you build it. Your first real video only ever touches the finished tool, in your own browser.

The recipe
  1. Open a normal chat and describe the tool
    No video needed yet. You're describing what the finished tool should do, not showing it anything.

    You don't need to understand every word below. It's written for the AI to read, not for you. Copy it exactly as it is.

    Prompt 
    Build me a single self-contained HTML file: I drop a video file on
it, it transcribes the speech on my own machine using a browser
speech-recognition model (such as Whisper via transformers.js),
shows me the captions as editable text with timestamps, lets me
fix any word, then burns the corrected captions into the video
(ffmpeg compiled for the browser is acceptable) and lets me
download the result. Everything must run locally in the browser:
the video must never upload to any server. Show a clear progress
bar, because this takes time.
    ROLE:
You are building me a small, self-contained tool. I am not a
coder, assume I will open one file and use it.

GOAL:
A single HTML file that captions a video from start to finish on
my own machine: transcribe, let me correct, burn the captions in,
hand me the finished file.

CONTEXT:
The video is sensitive enough that it must never leave this
computer. Everything runs locally in the browser, a browser
speech-recognition model (such as Whisper via transformers.js)
for the transcript, and ffmpeg compiled for the browser is
acceptable for burning captions in.

STEPS:
Build the page so that:
1. I drop a video file onto it.
2. It transcribes the speech locally and shows me the captions as
   editable text with timestamps.
3. I can fix any word before anything is rendered.
4. It burns the corrected captions into the video and lets me
   download the result.
5. A clear progress bar runs throughout, because this takes time
   and a frozen-looking page reads as broken.

OUTPUT:
One self-contained HTML file, plus a short plain-language note on
how to open it and what to expect the first time. The video must
never upload to any server.
  2. Save the file, then test with a short clip first
    Something under a minute. The first run downloads a speech-recognition model, several hundred megabytes, one time only. Give it a minute before you decide something's broken.
  3. Edit the captions before you burn them in
    Names and program terms are exactly what it gets wrong. The editing pane is where you catch that, so use it every time rather than only when something looks off.
  4. Expect it to be slow, which is the trade-off for keeping it local
    A ten-minute video can take a while on an older laptop, especially the first time. That slowness is the price of the video never leaving your machine.
What you walk away with

A downloaded video with captions burned in, and a reusable tool for the next one. No per-minute fee, and nothing uploaded.

Local isn't always the right call, and that's fine. If a video is public anyway and speed matters more than privacy, uploading it to a captioning service is a reasonable choice. This recipe is for the videos you'd never upload, and for getting off per-minute pricing.
