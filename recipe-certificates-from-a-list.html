Your Data, Handled · Generate

Certificates From a List

Certificates, name tags, and letters for everyone on your volunteer list. You get a page that turns your CSV into a print-ready stack, in place of the afternoon this usually takes after every event.

Nothing to flag. No sensitive data goes in, and nothing gets published
Information you give it

Your list's column names, not the list itself, and one example of the finished thing: last year's certificate as a photo or PDF, an old name badge, or the recognition letter you wrote by hand. The example carries the design, so you never have to describe fonts or layouts in words.

The recipe
  1. Dig up last year's example
    The certificate you made by hand, a badge from the last event, or the letter you liked. A photo or PDF works fine. Swap the real name for a made-up one if you'd rather.
  2. Note your list's column names
    Open your attendee or volunteer export and copy just the header row, such as "First Name, Last Name, Hours, Program." The names underneath stay where they are.
  3. Open a chat, attach the example, paste this
    Swap in your column names and event details. The attached example handles the design.

    You don't need to understand every word below. It's written for the AI to read, not for you. Swap in the [bracketed] parts and copy the rest exactly as it is.

    Prompt 
    I've attached [last year's volunteer certificate], and I want new
ones that look and feel like this.

Build me a SINGLE self-contained HTML file (no internet needed) that
lets me drag my CSV of volunteers onto the page and generates one
certificate per row, ready to print from the browser. My CSV's
columns are: [First Name, Last Name, Hours, Program].

Details:
- Match the attached example's layout, wording, and tone. The
  event is [the 2026 Volunteer Recognition Dinner] and each one
  should say [the volunteer's full name and their total hours].
- Format each page for [landscape US Letter, one per page].
- Read the CSV in my browser only: the names must never be
  uploaded anywhere.
- Show me the first one on screen as a preview before I print,
  and flag any rows with missing or odd-looking names so I can
  fix them first.
    ROLE:
You are building me a small, self-contained tool. I am not a
coder, assume I will open one file and use it.

GOAL:
Turn a CSV of people into a stack of print-ready certificates
that look like the one we already use.

CONTEXT:
I have attached [last year's volunteer certificate], and I want new ones that look and feel
like this. My CSV's columns are: [First Name, Last Name, Hours, Program]. The event is [the 2026 Volunteer Recognition Dinner],
and each certificate should say [the volunteer's full name and their total hours].

STEPS:
Build a SINGLE self-contained HTML file (no internet needed) that:
1. Lets me drag my CSV of volunteers onto the page and generates one certificate per row, ready to
   print from the browser.
2. Matches the attached example's layout, wording, and tone.
3. Formats each page for [landscape US Letter, one per page].
4. Reads the CSV in my browser only: the names must never be
   uploaded anywhere.
5. Shows me the first certificate on screen as a preview before
   I print.
6. Flags any rows with missing or odd-looking names so I can fix
   them first.

OUTPUT:
One HTML file I can double-click, plus one line on how to print
correctly (paper size and margins).
  4. Drop your real list on and preview
    Skim the previews and look for the usual mail-merge problems: a name in ALL CAPS, a stray middle initial, a blank row that became "Certificate of Appreciation for ".
  5. Print one. Then print eighty
    Run a single page first and check it on paper: margins, name placement, nothing clipped. Then send the whole stack.
Print one before printing eighty. Problems that are invisible on screen show up on paper: a margin off by a centimeter, a font that didn't load, a name that overflows its line. Find those on page one rather than on eighty sheets of the good cardstock.
What you walk away with

A generator you keep. This event it makes certificates; next event, you drop in the new list. Ask once more with a badge as the example and you have name tags too. The afternoon of copying, pasting, and renaming becomes about ten minutes of dragging, previewing, and printing.
