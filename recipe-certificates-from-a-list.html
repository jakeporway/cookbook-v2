Information you give it

Your list's column names (not the list itself) and one example of the finished thing — last year's certificate as a photo or PDF, an old name badge, the recognition letter you wrote by hand. The example carries the design; you never have to describe fonts or layouts in words.

The recipe
  1. Dig up last year's example
    The certificate you made by hand, a badge from the last event, or the letter you liked. A photo or PDF is perfect. Swap the real name for a made-up one if you'd rather.
  2. Note your list's column names
    Open your attendee or volunteer export and copy just the header row — "First Name, Last Name, Hours, Program" or whatever yours says. The names underneath stay put.
  3. Open a Claude chat, attach the example, paste this
    Swap in your column names and event details. The attached example does the design talking.
    Prompt
    I've attached [last year's volunteer certificate] — I want new
ones that look and feel like this.

Build me a SINGLE self-contained HTML file (no internet needed) that
lets me drag my CSV of volunteers onto the page and generates one
certificate per row, ready to print from the browser. My CSV's
columns are: [First Name, Last Name, Hours, Program].

Details:
- Match the attached example's layout, wording, and tone. The
  event is [the 2026 Volunteer Recognition Dinner] and each one
  should say [the volunteer's full name and their total hours].
- Format each page for [landscape US Letter, one per page].
- Read the CSV in my browser only — the names must never be
  uploaded anywhere.
- Show me the first one on screen as a preview before I print,
  and flag any rows with missing or odd-looking names so I can
  fix them first.
  4. Drop your real list on and preview
    Skim the previews. Look for the classic mail-merge gremlins: a name in ALL CAPS, a stray middle initial, a blank row that became "Certificate of Appreciation for ".
  5. Print one. Then print eighty
    Run a single page first and check it on paper — margins, name placement, nothing clipped. Then send the whole stack.
Print one before printing eighty. Screens forgive; printers don't. A margin that's off by a centimeter, a font that didn't load, a name that overflows its line — you want to find that on page one, not on a stack of eighty sheets of the good cardstock.
What you walk away with

A generator you keep. This event it's certificates; next event, drop in the new list. Ask once more with a badge as the example and you have name tags too. The afternoon of copy-paste-rename becomes ten minutes of drag-preview-print.
