Information you give it

The public document itself — the exact 400-page PDF you already ctrl-F through every week. That's it. You write nothing and explain nothing; the expertise is already sitting in the manual, you're just making it answerable.

The recipe
  1. Create a Project and name it after the document
    In Claude, click Projects → New project. Name it something you'll recognize in a hurry — "Medicaid Provider Manual 2026," not "My Project."
  2. Upload the PDF to Project knowledge
    On the Project page, use Add content (the knowledge panel) and upload the manual. If it lives in chapters or appendices as separate PDFs, upload them all — the expert should know the whole thing.
  3. Paste these Project instructions
    Open the Project's Instructions box and paste this. It's what makes the expert trustworthy instead of merely confident.
    Project instructions
    You are an expert on the document(s) in this Project:
[the 2026 State Medicaid Provider Manual]. I work at a nonprofit
and use this manual to make real compliance decisions, so accuracy
matters more than speed.

Answer questions using ONLY these documents. Always quote the exact
passage you're drawing from and cite the page or section number so I
can verify it before I act. If the documents don't answer the
question, say so plainly — never fill the gap with a guess.

If a rule has exceptions, conditions, or cross-references elsewhere
in the manual, point those out even if I didn't ask. If my question
uses different words than the manual does (I say
"copay," it says "cost-sharing"), tell me the manual's term so I
learn to search it myself too.
  4. Ask your first real question — a question you already know the answer to
    Start a chat inside the Project and ask something you've looked up before. Check that the quote and page number match the actual PDF. This one calibration question tells you how much to trust the rest.
  5. Use it all year — and verify the cite each time
    Every future chat in this Project already knows the manual. The habit that makes it safe: click through to the cited page before you act on the answer. It takes thirty seconds instead of the thirty minutes the search used to.
What you walk away with

A standing expert on the document you dread. Your weekly ctrl-F session becomes a question and a page number to double-check. When the agency publishes a new edition, you swap one file and the expert is current again.

Never act on an uncited answer. The cite-the-page rule isn't decoration — it's the entire safety mechanism of this recipe. An answer with a page number is a lead you can verify in seconds; an answer without one is just a plausible-sounding sentence. If the expert ever answers without quoting the manual, ask it to show you the passage — and if it can't, treat the question as unanswered.
