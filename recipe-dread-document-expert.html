Build an Expert · Ask

The dread-document expert

Load the Medicaid manual, the HUD handbook, or your state's licensing regulations into a Project once, then ask it questions all year. It cites the page every time, so you can verify before you act.

Nothing to flag. No sensitive data goes in, and nothing gets published
Information you give it

The public document itself: the same 400-page PDF you already search through every week. That's all. You write nothing and explain nothing. The expertise is already in the manual, and you're just making it answerable.

The recipe
  1. Create a Project and name it after the document
    In your AI chat, click Projects → New project. (In ChatGPT they're Projects in the left sidebar; Gemini calls them Gems.) Name it something you'll recognize in a hurry, such as "Medicaid Provider Manual 2026" rather than "My Project."
  2. Upload the PDF to Project knowledge
    Every Project has a files area, and documents you put there are visible to every chat you start inside that Project. On the Project page, use Add content and upload the manual. If it comes as separate PDFs for chapters or appendices, upload all of them so the expert knows the whole document.
  3. Paste these Project instructions
    Open the Project's Instructions box and paste this. It's what makes the answers verifiable rather than just confident.

    You don't need to understand every word below. It's written for the AI to read, not for you. Swap in the [bracketed] parts and copy the rest exactly as it is.

    Project instructions 
    You are an expert on the document(s) in this Project:
[the 2026 State Medicaid Provider Manual]. I work at a nonprofit
and use this manual to make real compliance decisions, so accuracy
matters more than speed.

Answer questions using ONLY these documents. Always quote the exact
passage you're drawing from and cite the page or section number so I
can verify it before I act. If the documents don't answer the
question, say so plainly — never fill the gap with a guess.

If a rule has exceptions, conditions, or cross-references elsewhere
in the manual, point those out even if I didn't ask. If my question
uses different words than the manual does (I say
"copay," it says "cost-sharing"), tell me the manual's term so I
learn to search it myself too.
    ROLE:
You are an expert on the document(s) in this Project: [the 2026 State Medicaid Provider Manual]. Your
expertise is bounded by those documents and nothing else.

GOAL:
Answer my questions about this material accurately enough that I
can act on the answer — or tell me plainly that the documents
don't answer it.

CONTEXT:
I work at a nonprofit and use this manual to make real compliance
decisions, so accuracy matters more than speed. I am not a
specialist in this material; I may use everyday words where the
document uses a term of art.

STEPS:
1. Answer using ONLY the documents in this Project.
2. Quote the exact passage you are drawing from and cite the page
   or section number, so I can verify it before I act.
3. If the documents don't answer the question, say so plainly.
   Never fill the gap with a guess or with general knowledge of
   how these rules usually work.
4. If a rule has exceptions, conditions, or cross-references
   elsewhere in the manual, point those out even if I didn't ask.
5. If my question uses different words than the manual does (I
   say "copay," it says "cost-sharing"), tell me the manual's term, so I learn to search
   it myself too.

OUTPUT:
A direct answer, the quoted passage with its page or section, any
exceptions or cross-references, and the manual's own terminology
where mine differed.
  4. Ask a first question you already know the answer to
    Start a chat inside the Project and ask something you've looked up before. Check that the quote and page number match the actual PDF. This one calibration question tells you how much to trust the rest.
  5. Use it all year, and check the citation each time
    Every future chat in this Project already knows the manual. The habit that keeps it safe is clicking through to the cited page before you act on the answer, which takes about thirty seconds instead of the thirty minutes the search used to. Set a recurring calendar reminder now to check for a new edition, timed to when the agency usually republishes. It's easy to forget otherwise.
What you walk away with

A standing expert on the document you dread. Your weekly search session becomes a question and a page number to double-check. When the agency publishes a new edition, you swap one file and the expert is current again.

Never act on an uncited answer. The cite-the-page rule is the entire safety mechanism of this recipe. An answer with a page number is something you can verify in seconds. An answer without one is just a plausible-sounding sentence. If the expert answers without quoting the manual, ask it to show you the passage. If it can't, treat the question as unanswered.
