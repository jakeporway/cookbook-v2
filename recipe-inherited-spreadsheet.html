Explain This Spreadsheet I Inherited

Your predecessor left a workbook with 11 tabs, colored cells, and formulas nobody understands, and then left the org. Hand it over and get a plain-language map: what each tab is for, what calculates what, and which cells everything else depends on.

Nothing to flag. No sensitive data goes in, and nothing gets published
Information you give it

The workbook itself, "FY24 MASTER TRACKER v7 (USE THIS ONE).xlsx", exactly as your predecessor left it. Better still, a copy with the dollar figures blanked out. The tabs, formulas, and colored cells are what need explaining, and those aren't the sensitive part. You point at the file rather than describing it.

The recipe
  1. Make a copy, and decide what to blank
    Save a copy of the workbook first and attach the copy, never the original. If it holds donor gifts, salaries, or client information, select those value columns in the copy and delete the contents, leaving the headers and formulas in place. The structure is what needs explaining. If you're not sure whether deleting a number will break a formula, leave it alone: attach the file as it is and tell the AI "the dollar figures are sensitive, so explain the structure but don't repeat the numbers back to me.""
  2. Open a chat and attach the copy
    Use the paperclip, the same as attaching a file to an email. This is the point where the file leaves your machine, which is why you're sending the blanked copy.
  3. Ask for the map
    Paste this, with one sentence of context about what the workbook is supposed to track.

    You don't need to understand every word below. It's written for the AI to read, not for you. Swap in the [bracketed] parts and copy the rest exactly as it is.

    Prompt 
    I inherited this workbook from someone who has left the
organization, and nobody here fully understands it. It's supposed
to track [our fundraising pipeline and gift entry for FY24].
I've blanked some values, please explain the structure, not the
numbers.

Give me a plain-language map, assuming I'm comfortable with
spreadsheets but new to THIS one:

1. One paragraph per tab: what it's for and whether anything
   else depends on it.
2. How the tabs feed each other: which ones I type into, and
   which ones calculate themselves.
3. The load-bearing cells: the ones where a careless edit would
   quietly break totals elsewhere. Tell me exactly where they
   are (tab and cell) and what they do.
4. Anything that looks broken, orphaned, or suspicious: formula
   errors, tabs nothing references, a hidden sheet.
5. What the colors and any cryptic column headers seem to mean,
   and say plainly when you're guessing.

I'll ask follow-ups about specific cells after I read this.
    ROLE:
You are a spreadsheet archaeologist. You explain how a workbook
is built and where it is fragile: you are not auditing its
numbers.

GOAL:
A plain-language map of this workbook good enough that I can work
in it without quietly breaking something.

CONTEXT:
I inherited this workbook from someone who has left the
organization, and nobody here fully understands it. It's supposed
to track [our fundraising pipeline and gift entry for FY24]. I've blanked some values, explain the
structure, not the numbers. Assume I'm comfortable with
spreadsheets but new to THIS one.

STEPS:
1. Walk every tab, including hidden ones.
2. Trace how the tabs feed each other: which ones I type into,
   and which ones calculate themselves.
3. Find the load-bearing cells: the ones where a careless edit
   would quietly break totals elsewhere.
4. Look for anything broken, orphaned, or suspicious: formula
   errors, tabs nothing references, a hidden sheet.
5. Interpret the colors and any cryptic column headers, and say
   plainly when you're guessing.

OUTPUT:
1. One paragraph per tab: what it's for and whether anything else
   depends on it.
2. How the tabs feed each other.
3. The load-bearing cells, each given as tab and cell, with what
   it does.
4. The broken / orphaned / suspicious list.
5. What the colors and cryptic headers seem to mean, guesses
   labeled as guesses.

I'll ask follow-ups about specific cells after I read this.
  4. Interrogate it while the file is still in view
    This is where most of the value is. "What happens if I add a row to the Gifts tab?" "Why is cell C47 red?" "Which tab does the board report actually pull from?" Ask everything you'd have felt awkward asking a colleague.
  5. Save the map into the workbook itself
    Paste the explanation into a new first tab called "READ ME: how this works." Check the two or three most important claims yourself before you rely on them. The next person to inherit this file will start from a map instead of a mystery.
This file does go to the chat. That's what makes this recipe amber rather than green. If the workbook holds donor gifts, salaries, or anything about the people you serve, blank those values in your copy first. The structure is what needs explaining, and it survives with the numbers gone. When in doubt, blank it out.
What you walk away with

A plain-language owner's manual for a workbook that used to live in one departed person's head: which tabs to touch, which cells to leave alone, and what's quietly broken. Plus a READ ME tab so nobody at your org inherits a mystery again.
