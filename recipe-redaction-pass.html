Your Data, Handled · Protect

The Redaction Pass

A little tool on your own computer that strips names, emails, phone numbers, and addresses from any text you paste in — so you can safely use every other recipe in this book on real material. Read this one first.

Nothing to flag — no sensitive data in, nothing published out
Information you give it

A description of what counts as identifying in your context — nothing real. Something like: "client names, staff names, school names, phone numbers, and our internal case IDs, which look like CL-1234." You already know this list by heart; you just say it out loud.

The recipe
  1. List what counts as identifying at your org
    Names, obviously — but also the sneaky ones: school names, shelter locations, your internal ID format. Two minutes with a sticky note. No real examples needed.
  2. Open a normal chat and paste this
    Swap in your own list of identifying things. The AI never needs to see a real name to build this.

    You don't need to understand every word below — it's instructions for the AI, not for you. Swap the [bracketed] parts; copy the rest exactly as-is.

    Prompt
    Build me a SINGLE self-contained HTML file (no internet needed, no
libraries loaded from the web) that redacts identifying information
from text I paste in. It must work entirely in my browser — nothing
I paste should ever be sent anywhere.

What counts as identifying for me:
[people's names, email addresses, phone numbers, street addresses,
school names, and our internal case IDs, which look like CL-1234]

How it should work:
- One big box where I paste text, a Redact button, and the cleaned
  version below with a Copy button.
- Replace each item with a consistent placeholder — the same person
  becomes [PERSON-1] every time they appear, so the text still
  makes sense.
- Highlight everything it changed so I can review each one.
- Let me click any word it MISSED to redact it by hand, and add
  that word to the list for next time.
- Include a note on the page reminding me to spot-check before
  pasting the result anywhere.
  3. Save the HTML file the AI hands back
    Put it somewhere you'll actually find it — your desktop is fine. Double-click to open. It works with your wifi off, and that's the point.
  4. Test it on text you already know
    Write a fake case note with made-up names, a fake phone number, and a fake ID in your format. Run it through. Did it catch everything? Click anything it missed to teach it.
  5. Make it the habit
    From now on: real text goes through this tool first, then into any chat. That one pass is what turns this book's amber recipes green for you.
Test before you trust. This tool is the key that unlocks the amber recipes in this book — so make sure the key works. Run it on text you know well and check that it caught every name, number, and ID. A pattern-matcher is thorough but literal: "Dr. J." or a nickname can slip past. Spot-check the output every time; you are the last line.
What you walk away with

A redaction tool that lives on your own computer and never phones home — plus a new habit. Every recipe in this book that says "paste your text in" now has a safe on-ramp: redact first, paste second. This one tool moves whole categories of your work from "can't touch AI" to "can."
