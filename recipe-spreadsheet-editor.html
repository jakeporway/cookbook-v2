The recipe

New here? Build the Viewer (Recipe 02) first — this recipe adds editing on top of that prompt.

  1. Start from the Viewer prompt
    Same move as Spreadsheet → Viewer — describe your columns to a normal Claude chat — then add the lines below to make it editable.
  2. Ask for an editable grid and an Export button
    These extra lines turn the read-only view into a tool you can fix data in.

    You don't need to understand every word below — it's instructions for the AI, not for you. Swap the [bracketed] parts; copy the rest exactly as-is.

    Prompt (add to the Viewer prompt)
    Also make the table editable — I want to fix values directly in
the page, add rows, and delete rows. Highlight any cell that was blank
or unreadable in my file so I know what to fix, and show a running
total at the top that updates as I edit.

Add an "Export clean CSV" button that downloads my edited data as
a new file. Important: it should NOT try to save or remember anything
on its own — I'll export when I'm done.
  3. Open it and fix the highlighted cells
    The blanks the Viewer flagged are marked here. Type the right value and the running total updates live, so a fix feels real.
  4. Hit Export — and understand what just happened
    A corrected file downloads. Read the note below before you rely on it.
    This is a worksheet, not a database. Your edits live only on the page until you Export. That's the browser line: the moment a tool needs to truly remember on its own, talk to other systems, or be used by many people at once, you've outgrown a single file — and that's okay. Here, Export is how you keep your work. Close the tab without exporting and it starts fresh from your original.
What you walk away with

A clean, corrected CSV you can hand to anyone — fixed in minutes, without uploading a thing. Plus the reusable worksheet tool itself, and a real feel for the browser line you'll meet again and again.
