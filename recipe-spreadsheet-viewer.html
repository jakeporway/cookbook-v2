Spreadsheet → Viewer

Hand the AI a description of your messy spreadsheet and get back a clickable dashboard with a sortable table, charts, and totals, running on your own computer. No coding, and nothing uploaded.

▶ See the working tool we builtA live City Harvest food-rescue dashboard. Drag your own CSV onto it.
Nothing to flag. No sensitive data goes in, and nothing gets published
Information you give it

Two or three made-up rows showing your column names. That's all the AI needs. Your real spreadsheet never gets pasted anywhere; you drop it on the finished tool, on your own computer.

The recipe
  1. Open a normal chat
    No special mode. Vanilla chat is all you need to get the tool written.
  2. Describe your columns and paste two fake rows
    The AI only needs the shape of your data rather than the real thing. Paste this, swapping in your own column names. Your column names are the words in row 1 when you open the file in Excel or Google Sheets.

    You don't need to understand every word below. It's written for the AI to read, not for you. Swap in the [bracketed] parts and copy the rest exactly as it is.

    Prompt 
    I export a spreadsheet as CSV. The columns are:
[Date, Source/Donor, Category, Amount, Location, Notes].

Build me a SINGLE self-contained HTML file (no internet needed, no
libraries loaded from the web) that lets me drag my CSV onto the page
and shows: totals and the date range at the top, a bar chart by a
group I can switch, a line chart over time, and a sortable, searchable
table of every row.

It must read the CSV in my browser only — my data should never be
uploaded anywhere. My file is messy: mixed date formats, some numbers
blank or written like "880 lbs" or "1,240", and the same name spelled
two ways. Handle that, and show me a short note listing what you cleaned
so I can trust the numbers.
    ROLE:
You are building me a small, self-contained tool. I am not a
coder — assume I will open one file and use it.

GOAL:
See what's actually in my spreadsheet — totals, trends, and every
row — without uploading it anywhere.

CONTEXT:
I export a spreadsheet as CSV. The columns are: [Date, Source/Donor, Category, Amount, Location, Notes].

My file is messy: mixed date formats, some numbers blank or
written like "880 lbs" or "1,240", and the same name spelled two
ways.

STEPS:
Build a SINGLE self-contained HTML file (no internet needed, no
libraries loaded from the web) that lets me drag my CSV onto the page and shows:
1. Totals and the date range at the top.
2. A bar chart by a group I can switch.
3. A line chart over time.
4. A sortable, searchable table of every row.
It must read the CSV in my browser only — my data should never be uploaded
anywhere. Handle the mess above, and show me a short note listing what you cleaned so I can trust the
numbers.

OUTPUT:
One HTML file I can double-click, with the cleaning note visible
on the page rather than buried in a tooltip.
  3. Download the HTML file the AI hands back
    It arrives as a file you can click. Save it somewhere you'll find it. This isn't a program you install. It's a single webpage that opens in Chrome or Safari like any website, stored on your own computer.
  4. Drag your real CSV onto it
    The charts and table fill in right away, and the file never left your computer.
  5. Reuse it every month
    Drop in a fresh export to refresh everything. No rebuilding, no re-prompting.
What you walk away with

A reusable, offline dashboard tool. It isn't a one-time answer: drop in next month's export and it refreshes itself. It also tells you what it had to clean up, so you can trust the totals.
